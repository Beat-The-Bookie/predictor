Updates

A log of changes and improvements since last season.

  • Complete UI Revamp
    The introduction of a proper mobile website, because for some silly reason I thought people would use desktop only.
  • Email Permissions
    You can now choose which emails you want to receive from us. This means people can opt out if they wish.
  • The "PimmDoggyDogg Update"
    A check when you leave the page to ensure you have saved changes - named after Kevin who rued his mistake in La Liga most Monday evenings throughout the season.
  • Remove Draggable Teams
    The ability to drag and drop teams in the prediction table has been removed due to the fact that it was not working properly on mobile devices. Instead, the up/down arrows have been added.
  • Full Previous Season Table
    Someone (can't remember who) suggested that it would be nice to see the full table from the previous season, so this has been added to the bottom of the league pages.
